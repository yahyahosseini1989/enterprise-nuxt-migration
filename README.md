# 🏦 سامانه مدیریت تراکنش‌های بانکی (نسخه Legacy)

> ⚠️ **وضعیت پروژه: منسوخ شده (Deprecated)** 
> این ریپازیتوری شامل کدهای معماری قدیمی (Nuxt 2 + Vuex) است و توسعه آن متوقف شده است. 
> برای مشاهده نسخه مدرن این سامانه، لطفاً به ریپازیتوری [لینک ریپازیتوری Nuxt 3 شما] مراجعه کنید.

## 🎯 هدف این پروژه
این پروژه به منظور شبیه‌سازی کدهای Legacy یک سامانه بانکی سازمانی توسعه داده شده است تا چالش‌های معماری قدیمی و رفع بدهی‌های فنی (Technical Debts) را به نمایش بگذارد.

## 🛠️ تکنولوژی‌های استفاده شده (Legacy Stack)
* **فریم‌ورک:** Nuxt.js (v2) / Vue 2 (Options API)
* **مدیریت استیت:** Vuex (Modularized)
* **احراز هویت:** Cookie-based با استفاده از `nuxtServerInit`
* **مدیریت الگوها:** Mixins و Global Plugins
* **استایل‌دهی:** Tailwind CSS

## 📈 دستاوردهای معماری در این نسخه
۱. پیاده‌سازی گیت‌های امنیتی با Middlewares
۲. مدیریت خطاهای ۴۰۱ به صورت متمرکز با Axios Interceptors
۳. استفاده از الگوی Adapter برای نرمال‌سازی دیتای API
۴. جلوگیری از تداخل DOM در سمت سرور با `<client-only>`
